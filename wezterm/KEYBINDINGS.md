# WezTerm Keybindings

Leader: `Ctrl+Space`

## Painéis

| Atalho | Ação |
|---|---|
| `Leader + v` | Split lateral (vertical) |
| `Leader + -` | Split horizontal |
| `Leader + h/j/k/l` | Navegar entre painéis |
| `Leader + z` | Zoom no painel (toggle) |
| `Leader + x` | Fechar painel |

## Abas

| Atalho | Ação |
|---|---|
| `Leader + c` | Nova aba |
| `Leader + n` | Próxima aba |
| `Leader + p` | Aba anterior |
| `Leader + ,` | Renomear aba |
| `Leader + 1..9` | Ir para aba por número |

## Workspaces

| Atalho | Ação |
|---|---|
| `Leader + S` | Criar/ir para workspace pelo nome |
| `Leader + s` | Listar workspaces (fuzzy) |
| `Leader + Tab` | Workspace anterior |
